**`v1410-1`, `claudebox`, and `oraclebox1`** — a 3-voter set.

This file is the *declarative source of truth* for server membership. Direct SSH
administration of the masters is not assumed (e.g. `v1410-1` has no `ubuntu` login,

`oraclebox1`, see `conductor/CONDUCTOR.md`) treats reaching this state as a standing,
long-running convergence task: apply what it can, record what it can't, retry over time.

## Joining rules (apply to every master)

1. **Exactly one bootstrapper.** `v1410-1` already bootstrapped the cluster. New masters
   (`oraclebox1`, `claudebox`) MUST **omit `bootstrap_expect`** and join via
   `server_join.retry_join`. A second `bootstrap_expect` would form a split-brain cluster.
2. **retry_join lists the other masters:** `["100.75.75.39", "100.125.210.126", "100.87.219.108"]`
   (a node may list the others; listing itself is harmless).
3. **region `global`, datacenter `dc1`** on all nodes (mismatches prevent Raft peering).
4. **Autopilot is tuned for WAN/Tailscale latency** (applied 2026-06-01):
   `last-contact-threshold=1s`, `server-stabilization-time=10s`, `cleanup-dead-servers=true`.
   The default 200ms threshold flapped because masters are ~50ms apart over Tailscale.

## claudebox revival procedure (pending — depends on the windesk diagnosis job)

`claudebox` is unreachable on Tailscale (relay only, rx 0). Diagnosis is delegated to
**`windesk`**, which shares claudebox's LAN (see `jobs/claudebox-diagnose.hcl`). Once
claudebox is reachable again:

1. **Stop any old standalone server** and **clear stale Raft state.** claudebox formerly ran
   as `bootstrap_expect=1` (sole server). Its old Raft data in `~/nomad/data` names itself
   leader of a *different* cluster and will refuse to join. With the agent stopped, move it
   aside: `mv ~/nomad/data ~/nomad/data.standalone.bak`. (Destructive to the *stale* state
   only — the authoritative state lives on v1410-1.)
2. **Start with the join config.** `scripts/claudebox-server.sh` has been updated to generate
   a joining config (retry_join, no bootstrap_expect). Run `claudebox-server.sh start`.
3. **Verify promotion.** From any master: `nomad operator raft list-peers` should list
   `claudebox.global` and autopilot should promote it to voter after stabilization, giving 3
   voters and FailureTolerance 1.
