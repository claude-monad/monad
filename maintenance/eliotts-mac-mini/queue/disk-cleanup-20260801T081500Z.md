10.30 GB free**. Nomad's own `PUT /v1/client/gc` has now been called on three separate sweeps

## What to do (run locally on the Mac, in this order, stop when under 90%)

```bash
du -xh -d1 ~ /opt /usr/local 2>/dev/null | sort -rh | head -20   # find the actual hogs first
rm -rf ~/Library/Caches/* 2>/dev/null                            # user caches, safe
npm cache clean --force 2>/dev/null; brew cleanup -s 2>/dev/null # toolchain caches
docker system prune -f 2>/dev/null                               # ONLY if docker is idle
find /opt/nomad/data/alloc -maxdepth 1 -type d -mtime +7 2>/dev/null | head  # inspect, don't blind-rm
```

Do **not** delete anything under the monad checkout, `~/Library/Application Support/Claude*`,
or live Nomad alloc dirs for running allocations.
